Шаг 5: Едем по пути

Pure Pursuit — третья ключевая функция

Задача

A* нашёл путь — набор точек на карте. Но путь — это не движение. Нужен алгоритм, который превратит «список координат» в «команды для моторов»: насколько быстро ехать и насколько поворачивать.

Pure Pursuit — алгоритм следования по пути. Робот выбирает точку «впереди по маршруту» (lookahead point) и всё время поворачивается к ней. Как осёл, который бежит за морковкой на палке.
Когда ты ведёшь машину, ты не смотришь себе под колёса — ты смотришь на дорогу метров на 10-20 вперёд и рулишь к той точке. Если дорога поворачивает — ты плавно доворачиваешь. Это и есть Pure Pursuit.

Как работает

1
Выбрать lookahead point — точку на пути, которая находится на расстоянии L (lookahead distance) от робота. Не самую ближнюю, а «впереди по маршруту».
2
Посчитать угол к этой точке — разницу между текущим направлением робота и направлением на lookahead point.
3
Превратить угол в команду — если нужно повернуть немного → маленькая угловая скорость. Много → большая. Прямо → только линейная.

Формулы

Угол к lookahead point

target_angle = atan2(lookahead_y - robot_y, lookahead_x - robot_x)

Разница углов (ошибка)

alpha = target_angle - robot_yaw

Важно нормализовать alpha в диапазон [-π, π], чтобы робот поворачивал в правильную сторону:

// Нормализация угла в [-π, π]
double normalizeAngle(double a) {
    while (a >  M_PI) a -= 2.0 * M_PI;
    while (a < -M_PI) a += 2.0 * M_PI;
    return a;
}

Команды движения

linear.x = V * cos(alpha) ← замедляемся при большом угле
angular.z = K * alpha ← поворот пропорционален ошибке

Где V — максимальная линейная скорость, K — коэффициент пропорциональности.

Код: purePursuitControl

// Параметры
const double LOOKAHEAD_DIST = 0.3;  // метры
const double MAX_LINEAR_VEL = 0.15; // м/с
const double MAX_ANGULAR_VEL = 1.0; // рад/с
const double GOAL_TOLERANCE = 0.15; // считаем «приехали» если < 15 см

void purePursuitControl() {
    if (current_path_.empty() || !has_goal_) return;

    // Проверяем: может, уже приехали?
    double dist_to_goal = std::hypot(goal_x_ - robot_x_, goal_y_ - robot_y_);
    if (dist_to_goal < GOAL_TOLERANCE) {
        // Стоп!
        auto cmd = geometry_msgs::msg::Twist();
        cmd_pub_->publish(cmd);  // все нули = остановиться
        has_goal_ = false;
        RCLCPP_INFO(this->get_logger(), "Цель достигнута!");
        return;
    }

    // Ищем lookahead point — первую точку пути дальше LOOKAHEAD_DIST от робота
    double lx = 0, ly = 0;
    bool found = false;

    for (auto& [gx, gy] : current_path_) {
        // Переводим клетку в метры
        double wx = ORIGIN_X + gx * RESOLUTION + RESOLUTION / 2;
        double wy = ORIGIN_Y + gy * RESOLUTION + RESOLUTION / 2;
        double d = std::hypot(wx - robot_x_, wy - robot_y_);

        if (d >= LOOKAHEAD_DIST) {
            lx = wx; ly = wy;
            found = true;
            break;
        }
    }

    if (!found) {
        // Все точки ближе чем lookahead — берём последнюю
        auto& [gx, gy] = current_path_.back();
        lx = ORIGIN_X + gx * RESOLUTION + RESOLUTION / 2;
        ly = ORIGIN_Y + gy * RESOLUTION + RESOLUTION / 2;
    }

    // Считаем угловую ошибку
    double target_angle = atan2(ly - robot_y_, lx - robot_x_);
    double alpha = normalizeAngle(target_angle - robot_yaw_);

    // Формируем команду
    auto cmd = geometry_msgs::msg::Twist();
    cmd.linear.x  = MAX_LINEAR_VEL * std::cos(alpha);  // тормозим при повороте
    cmd.angular.z = std::clamp(2.0 * alpha, -MAX_ANGULAR_VEL, MAX_ANGULAR_VEL);

    // Не ехать назад
    if (cmd.linear.x < 0) cmd.linear.x = 0;

    cmd_pub_->publish(cmd);
}

Настройка параметров

ПараметрЭффект увеличенияТипичное значение
LOOKAHEAD_DIST Более плавные повороты, но робот может срезать углы 0.2–0.5 м
MAX_LINEAR_VEL Робот едет быстрее, но хуже вписывается в повороты 0.1–0.22 м/с
K (коэфф. angular) Более резкие повороты. Слишком большой → осцилляции 1.0–3.0
GOAL_TOLERANCE Менее точная остановка, но робот не будет «кружить» вокруг цели 0.1–0.2 м

Если робот осциллирует (дёргается влево-вправо) — уменьши K или увеличь LOOKAHEAD_DIST. Если робот не вписывается в повороты — уменьши скорость или уменьши lookahead.

Бонус: экстренная остановка

Преподаватель требует, чтобы робот останавливался при обнаружении близкого препятствия. Это просто:

// В scanCallback, после обновления карты
void checkEmergencyStop(const sensor_msgs::msg::LaserScan::SharedPtr msg) {
    double min_range = std::numeric_limits<double>::infinity();

    // Проверяем лучи в переднем секторе (±30°)
    int center = msg->ranges.size() / 2;  // центральный луч = вперёд
    int spread = 30;                        // ±30 лучей (~±30°)

    for (int i = center - spread; i <= center + spread; i++) {
        if (i < 0 || i >= (int)msg->ranges.size()) continue;
        float r = msg->ranges[i];
        if (!std::isinf(r) && !std::isnan(r) && r < min_range) {
            min_range = r;
        }
    }

    // Если что-то ближе 20 см — стоп
    if (min_range < 0.20) {
        auto cmd = geometry_msgs::msg::Twist();
        cmd_pub_->publish(cmd);  // стоп
        RCLCPP_WARN(this->get_logger(), "Препятствие! %.2f м", min_range);
    }
}

Общий цикл управления

Все три функции работают вместе по таймеру:

// В конструкторе ноды — таймер на 10 Hz
timer_ = this->create_wall_timer(100ms, [this]() {
    if (has_goal_) {
        replan();              // 1. Обновить путь на актуальной карте
        purePursuitControl();  // 2. Рассчитать и отправить cmd_vel
    }
});

Полный цикл: /scan → updateMapWithLaser → replan (A*) → purePursuitControl → /cmd_vel → робот двигается → новый /scan → ...

Итоги шага

  • Pure Pursuit — выбирает точку «впереди» на пути и рулит к ней.
  • Lookahead — ключевой параметр. Больше = плавнее, но менее точно.
  • Результат — сообщение Twist в /cmd_vel (скорость + поворот).
  • Три ключевых функции написаны: updateMapWithLaser, planAStar, purePursuitControl.

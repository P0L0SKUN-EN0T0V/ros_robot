1. Что вообще делаем?

Задача в одном предложении: написать программу на C++, которая управляет виртуальным роботом в симуляторе — робот должен сам доехать из точки A в точку B, объезжая стены и препятствия.

Представь: есть виртуальная комната с роботом-тележкой. У робота есть лазерный сканер (видит стены) и одометр (знает, где находится). Твоя задача — написать «мозг» робота, который принимает эти данные и решает, куда ехать.

Всё это работает внутри Docker-контейнеров — изолированных виртуальных окружений, чтобы не засорять свой компьютер.

2. Зачем это нужно?

Чему научишься:

  • ROS2 — стандартная платформа для программирования роботов (промышленность, беспилотники, склады)
  • C++ в реальном проекте — не абстрактные задачки, а управление роботом
  • Docker — контейнеризация, без которой не обходится ни один серьёзный проект
  • Алгоритмы навигации — A*, RRT, Dijkstra — как робот планирует путь
  • Работа с сенсорами — лидар, одометрия, системы координат

Это не игрушечный проект. Те же технологии используют Boston Dynamics, Amazon Robotics, Tesla. Разница — масштаб, а принципы те же.

Дифф. роботДва ведущих колеса. Поворачивает разницей скоростей (как танк).

Простыми словами: Симулятор = «тело» робота (колёса, сенсоры, физика). Навигация = «мозг» (куда ехать, как объехать стену). Общаются по сети через топики.

5. Контейнер 1: Симулятор

Что внутри:

  • ROS2 Humble + Gazebo (3D-физика)
  • Модель робота (TurtleBot3 или своя)
  • Мир: комната со стенами и ящиками

Общий для всех групп — менять не нужно.

Публикует

/scan LaserScan

~360 чисел — расстояние до объектов вокруг робота (360°).

/odom Odometry

Позиция (x, y) и ориентация робота.

Принимает

/cmd_vel Twist

Линейная + угловая скорость. linear.x=0.5, angular.z=0.3 — вперёд с поворотом влево.

6. Контейнер 2: Навигация (твой код)

Главная часть. C++ алгоритм:

  1. 1Читает лидар (/scan) — видит препятствия
  2. 2Читает одометрию (/odom) — знает где находится
  3. 3Получает цель (/goal_pose или параметр)
  4. 4Строит карту проходимости из лидара
  5. 5Планирует путь (A*, RRT...)
  6. 6Едет по маршруту — публикует /cmd_vel
Запрещено: готовые пакеты навигации (Nav2, move_base). Только rclcpp и типы сообщений.

Компоненты

  • OccupancyGrid — 2D-сетка «проходимо / стена»
  • Global planner — поиск пути (A*, RRT...)
  • Local planner — ведёт по маршруту, объезжает препятствия (DWA)
  • Velocity publisher — план → команды /cmd_vel

9. Как запустить

Установить: Docker + Docker Compose + Git

ROS2 и Gazebo ставить НЕ нужно — всё внутри контейнеров.

# Клонировать и запустить
git clone https://github.com/your-team/ros_robot.git
cd ros_robot
docker-compose up --build

# Задать цель (другой терминал)
docker exec -it navigation_container \
  ros2 topic pub /goal_pose geometry_msgs/PoseStamped \
  '{header: {frame_id: "map"}, pose: {position: {x: 3.0, y: 2.0}}}'

# Остановить
docker-compose down

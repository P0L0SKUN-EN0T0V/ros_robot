1. Что вообще делаем?

Задача в одном предложении: написать программу на C++, которая управляет виртуальным роботом в симуляторе — робот должен сам доехать из точки A в точку B, объезжая стены и препятствия.

Представь: есть виртуальная комната с роботом-тележкой. У робота есть лазерный сканер (видит стены) и одометр (знает, где находится). Твоя задача — написать «мозг» робота, который принимает эти данные и решает, куда ехать.

Всё это работает внутри Docker-контейнеров — изолированных виртуальных окружений, чтобы не засорять свой компьютер.

2. Зачем это нужно?

Чему научишься:

  • ROS2 — стандартная платформа для программирования роботов
  • C++ в реальном проекте — управление роботом
  • Docker — контейнеризация
  • Алгоритмы навигации — A*, RRT, Dijkstra
  • Работа с сенсорами — лидар, одометрия

Те же технологии используют Boston Dynamics, Amazon Robotics, Tesla. Разница — масштаб, принципы те же.

Простыми словами: Симулятор = «тело» (колёса, сенсоры). Навигация = «мозг» (куда ехать). Общаются через топики.

6. Контейнер 2: Навигация (твой код)

  1. 1Читает лидар → видит препятствия
  2. 2Читает одометрию → знает где находится
  3. 3Получает цель → знает куда ехать
  4. 4Строит карту проходимости
  5. 5Планирует путь (алгоритм)
  6. 6Едет по маршруту → /cmd_vel
Запрещено: Nav2, move_base. Только rclcpp и типы сообщений.

9. Как запустить

Установить: Docker + Docker Compose + Git. ROS2/Gazebo ставить не нужно.

git clone https://github.com/your-team/ros_robot.git
cd ros_robot
docker-compose up --build

# Задать цель (другой терминал)
docker exec -it navigation_container \
  ros2 topic pub /goal_pose geometry_msgs/PoseStamped \
  '{header: {frame_id: "map"}, pose: {position: {x: 3.0, y: 2.0}}}'

docker-compose down
